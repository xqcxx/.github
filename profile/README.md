## What is OrbitPay?

OrbitPay is a **decentralized payroll and treasury management protocol** enabling:

- **Automated Payroll** — Stream salaries and recurring payments on-chain
- **Multi-Sig Treasury** — Configurable approval thresholds for withdrawals
- **Token Vesting** — Time-based lock schedules for team allocations
- **DAO Governance** — Proposals, voting, and on-chain policy changes
- **Full Transparency** — Every action recorded on-chain with event emissions

## Contributing

We welcome contributions! Each repo has its own `CONTRIBUTING.md`, but the general workflow is:

1. Pick an issue from the docs repo
2. Fork the relevant repo and create a feature branch
3. Submit a PR against `main`

All repos follow a shared [Code of Conduct](https://github.com/OrbitPay-Co/orbitpay-contracts/blob/main/CODE_OF_CONDUCT.md) and [Style Guide](https://github.com/OrbitPay-Co/orbitpay-contracts/blob/main/STYLE.md).
